# RobBob News Editor

Простой редактор новостей для RobBob Launcher.

## Использование

1. Откройте `admin/index.html` в браузере
2. Заполните форму:
   - **Заголовок**: Название новости (обязательно)
   - **Иконка**: Выберите подходящую иконку
   - **Содержание**: Краткое описание (обязательно)
   - **Дата**: Дата публикации (по умолчанию - сегодня)
   - **Ссылка**: URL для "Подробнее" (опционально)
   - **Закрепить**: Закреплённые новости показываются первыми

3. Нажмите "Добавить новость"
4. Повторите для других новостей
5. Скопируйте JSON из секции "Результат"

## Публикация новостей

### Вариант 1: GitHub Gist (Рекомендуется)

1. Перейдите на https://gist.github.com
2. Создайте новый Gist:
   - Filename: `news.json`
   - Content: Вставьте скопированный JSON
3. Нажмите "Create public gist"
4. Нажмите кнопку "Raw" и скопируйте URL
5. Обновите URL в `src/scripts/news.js`:
   ```javascript
   NEWS_URL: 'https://gist.githubusercontent.com/YOUR_USERNAME/GIST_ID/raw/news.json'
   ```

### Вариант 2: Свой сервер

1. Загрузите `news.json` на ваш сервер
2. Обновите URL в `src/scripts/news.js`:
   ```javascript
   NEWS_URL: 'https://your-server.com/path/to/news.json'
   ```

## Обновление новостей

1. Откройте редактор
2. Ваши предыдущие новости сохранены в браузере
3. Добавьте/удалите/отредактируйте новости
4. Скопируйте новый JSON
5. Обновите ваш Gist или файл на сервере

## Формат JSON

```json
{
  "version": 1,
  "lastUpdated": "2024-12-14T00:00:00.000Z",
  "news": [
    {
      "id": "news-123456789",
      "title": "Обновление v1.2",
      "emoji": "rocket",
      "content": "Новые функции и улучшения!",
      "date": "2024-12-14",
      "pinned": true,
      "link": "https://github.com/..."
    }
  ]
}
```

## Доступные иконки

- 🚀 `rocket` - Обновления
- 🛡️ `shield` - Безопасность
- ⚡ `zap` - Улучшения
- ⭐ `star` - Новинки
- 🔥 `fire` - Важные новости
- 🎉 `party` - События
- ⚠️ `warning` - Предупреждения
- ℹ️ `info` - Информация
- ✅ `check` - Исправления
- 🔄 `update` - Изменения

## Советы

- **Короткие заголовки**: Лучше воспринимаются пользователями
- **Краткий контент**: 1-2 предложения оптимально
- **Закрепление**: Используйте для важных объявлений
- **Ссылки**: Добавляйте для подробной информации
- **Регулярность**: Обновляйте новости периодически

## Кэширование

Лаунчер кэширует новости на 5 минут. Пользователи увидят обновления:
- При первом запуске
- После истечения кэша (5 минут)
- При переключении на страницу новостей

## Локальное хранение

Редактор сохраняет ваши новости в localStorage браузера, поэтому они не потеряются при обновлении страницы.
